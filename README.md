# Anime Search App

an anime search app that can search for anime and their detail

## Setup

1. download repo
2. open terminal and navigate to the directory and type "npm install"
3. type in "npm run dev" to start the project
4. open browser and copy the address show on the terminal, or type https://localhost:4000/ on the browser to view the project

## Usage

- search for anime
- view the detail for the anime

## Tech
- Vite
- React
